서비스 상태

API 엔드포인트

  • GET /api/health — 서비스 상태
  • GET /api/db/check — DB 연결 확인
  • GET /api/db/tables — 테이블 목록
  • POST /api/db/setup-tables — 테이블 생성
  • POST /api/db/seed-sample-data — 샘플 데이터 추가
